# OpenGL-3D-Clock-Scene-
A 3D computer graphics project developed in C++ using OpenGL as part of university coursework.

Overview

The application renders a 3D scene featuring a clock with a mechanical mechanism and an animated pendulum, placed inside a textured room. The project focuses on 3D transformations, texture mapping, shader programming, and real-time rendering.

Features

3D scene rendering using OpenGL

Custom 3D models and geometric transformations

Texture mapping for objects and environment

GLSL vertex and fragment shaders

Animated clock mechanism and pendulum

Interactive camera movement

Keyboard and mouse input handling

Technologies

C++

OpenGL

GLSL

GLFW

GLEW

GLM

LodePNG

Controls

W – Move forward

S – Move backward

A – Move left

D – Move right

Mouse – Rotate the camera

ESC – Exit the application

Build and Run

The project was developed for Windows using Microsoft Visual Studio.

Install Microsoft Visual Studio with the C++ desktop development workload.

Open cgv_st_07_win.sln.

Select the appropriate build configuration.

Build and run the application.

Required libraries and resources must be available in the expected project paths.

Project Context

This project was developed for educational purposes to practice computer graphics programming, 3D transformations, shader-based rendering, texturing, and animation.
